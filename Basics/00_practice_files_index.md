## 🎓 Learning Objectives by File

### **Array Methods Practice (`16_array_methods_practice.js`)**
- **Transform Methods**: `map()`, `filter()`, `reduce()`
- **Searching Methods**: `find()`, `findIndex()`, `includes()`
- **Sorting & Reversing**: `sort()`, `reverse()`
- **Adding/Removing**: `push()`, `pop()`, `splice()`
- **Slicing & Concatenation**: `slice()`, `concat()`, spread operator
- **Testing Methods**: `every()`, `some()`
- **Practical Examples**: Shopping cart, student grades, data transformation
- **Practice Exercises**: Prime numbers, longest word, duplicate removal

### **Object Methods Practice (`17_object_methods_practice.js`)**
- **Creation Methods**: Literals, constructors, `Object.create()`, factory functions
- **Property Methods**: `Object.keys()`, `Object.values()`, `Object.entries()`
- **Manipulation**: `Object.assign()`, spread operator, `Object.freeze()`, `Object.seal()`
- **Descriptors**: Property attributes, getters/setters
- **Prototypes**: Constructor functions, inheritance, prototype chain
- **Utility Methods**: Deep cloning, equality comparison, property symbols
- **Practical Examples**: Configuration management, validation, data transformation
- **Practice Exercises**: Deep cloning, property watchers, object merging

### **String Methods Practice (`18_string_methods_practice.js`)**
- **Creation & Conversion**: Literals, constructors, template literals
- **Properties & Length**: Character access, immutability
- **Searching Methods**: `indexOf()`, `search()`, `includes()`, `startsWith()`, `endsWith()`
- **Extraction Methods**: `slice()`, `substring()`, `charAt()`
- **Modification Methods**: `trim()`, `replace()`, case conversion
- **Splitting & Joining**: `split()`, `join()`, CSV processing
- **Comparison & Testing**: String comparison, regex testing
- **Template Literals**: Basic usage, tagged templates, multi-line strings
- **Practical Examples**: Text analysis, string formatting, password validation
- **Practice Exercises**: Vowel counting, word reversal, duplicate detection

### **Function Patterns Practice (`19_function_patterns_practice.js`)**
- **Declarations & Expressions**: Function types, hoisting, arrow functions
- **Parameters & Arguments**: Default values, rest parameters, destructuring
- **Higher-Order Functions**: Functions that return functions, function composition
- **Closures**: Lexical scoping, private variables, common pitfalls
- **Currying**: Partial application, function currying
- **Memoization**: Caching, performance optimization, TTL
- **Decorators**: Function wrappers, timing, logging, retry mechanisms
- **Practical Examples**: Event emitters, pipelines, rate limiting
- **Practice Exercises**: Throttling, once functions, promise patterns

### **Async Programming Practice (`20_async_promises_practice.js`)**
- **Callbacks**: Basic patterns, callback hell, error handling
- **Promises**: Creation, states, consumption, chaining
- **Promise Composition**: `Promise.all()`, `Promise.race()`, `Promise.allSettled()`
- **Async/Await**: Syntax, error handling, concurrent operations
- **Error Handling**: Try-catch, fallbacks, multiple request handling
- **Advanced Patterns**: Timeouts, retry mechanisms, promise queues
- **Practical Examples**: API clients, data pipelines, rate limiting
- **Practice Exercises**: Cancellable promises, promise pools, event emitters

### **ES6+ Modern Features (`21_es6_modern_features_practice.js`)**
- **Destructuring**: Array and object destructuring, nested destructuring, defaults
- **Spread Operator**: Array/object spreading, function arguments, copying
- **Template Literals**: Basic usage, multi-line strings, tagged templates
- **Arrow Functions**: Syntax, implicit returns, `this` context
- **Default Parameters**: Function defaults, expression defaults, destructuring defaults
- **Rest Parameters**: Function rest, destructuring rest, object rest
- **Modules**: Import/export syntax, named exports, default exports
- **Classes**: Basic classes, inheritance, static methods, getters/setters
- **Modern Methods**: `Array.from()`, `Object.entries()`, `find()`, `includes()`
- **Practical Examples**: Configuration builders, data transformers, event systems
- **Practice Exercises**: Array swapping, shopping carts, duplicate detection

## 🚀 How to Use These Files

### **1. Sequential Learning**
Start with the core fundamentals (files 01-15) to build a solid foundation, then progress to the advanced practice files (16-21).

### **2. Topic-Based Learning**
Focus on specific areas by choosing relevant practice files based on your learning goals.

### **3. Practice Approach**
- **Read**: Understand the concepts and examples
- **Run**: Execute the code to see results
- **Modify**: Experiment with different values and scenarios
- **Practice**: Complete the exercises at the end of each file
- **Build**: Create your own examples using the concepts learned

### **4. Running the Files**
```bash
# Run any practice file
node Basics/16_array_methods_practice.js
node Basics/17_object_methods_practice.js
# ... and so on
```
